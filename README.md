# بيت الرياضة

موقع هبوط لمحل أحذية رياضية ورسمية: فيلم يتحرك مع التمرير، أقسام منتجات بتأثير ثلاثي الأبعاد، ولوحة تحكم لإضافة المنتجات (`/admin`).

التقنية: TanStack Start + React، يُبنى بـ Nitro لخادم Node.js. البيانات في ملف JSON واحد (`store.json`) والصور المرفوعة على القرص، بدون قاعدة بيانات خارجية.

## النشر على هوستنجر (Node.js Web App)

1. **المتطلبات:** خطة تدعم تطبيقات Node.js، وإصدار Node **22** (الحد الأدنى 20.19 لأن أداة البناء Vite 8 تشترط ذلك).
2. **الربط:** اربط المستودع واختر الفرع `main`.
3. **إعدادات البناء:**
   - Build command: `npm run build`
   - Output directory: `.output`
   - Entry file: `server/index.mjs`
   - (أو أمر التشغيل: `npm start`)
4. **متغيرات البيئة:**
   - `DATA_DIR`: مجلد يحفظ قاعدة البيانات والصور المرفوعة، ويفضل أن يكون **خارج** مجلد التطبيق (مثل `/home/USERNAME/bayt-data`) حتى لا تُمسح عند إعادة النشر. إن لم يُحدد فالقيمة الافتراضية `./data`.
   - `PORT` و`HOST`: تضبطهما هوستنجر عادة تلقائياً.
5. **بعد أول نشر:** افتح `/admin` فوراً وأنشئ كلمة مرور المدير (أول من يفتح الصفحة هو من يحدد كلمة المرور)، ثم أضف رقم واتساب وبيانات المحل والماركات.

## التشغيل محلياً

```bash
npm install
npm run dev                  # تطوير
npm run build && npm start   # إنتاج
```

## الملفات المهمة

- `src/scroll-scrub-scenes.tsx`: نص الفيلم وعنوانه.
- `src/components/bayt/`: أقسام الصفحة.
- `src/styles.css`: الألوان والتصميم.
- `src/lib/db.server.ts`: قاعدة البيانات وتخزين الصور.
- `public/assets/world/`: ملفات الفيلم (سطح المكتب والهاتف).

## استكشاف الأخطاء

- **رسالة 403 Forbidden:** تعني أن هوستنجر تقدم المجلد كموقع ثابت ولا تشغّل Node. أنشئ التطبيق من نوع **Node.js Web App** لا موقعاً ثابتاً.
- **فشل البناء:** تأكد أن إصدار Node في إعدادات التطبيق 22 (أو 20.19+)، وأن أمر البناء `npm run build`.
- **المنتجات تختفي بعد النشر:** اضبط `DATA_DIR` على مجلد خارج مجلد التطبيق.
